## M1 交付内容

- 嵌套 struct 扁平展开、定长数组、`std::vector` Sequence、`std::string`。
- 全定长类型保持 `kFixedRaw` 零拷贝；含变长字段走 `kPacked` tagged 编码。
- `ObjectCodec` + `DynamicObject`；未知字段跳过、缺失字段零默认。
- Schema wire v0.2（layout/element_kind/element_size/flags）+ 指纹索引 + 重复 FieldID 拒绝。
- Node `register_type_typed` / `publish_typed` / `subscribe_typed` / `publish_dynamic` / `subscribe_dynamic`，帧头携带 `schema_id`。
- `examples/isdm_demo_complex_types` 端到端 Demo。
- 已知限制：`typed_types_` 按 TypeId 缓存（M2 多版本需改）；`subscribe_dynamic` 尚未按 sender `schema_id` 选择版本（M2）；`retain()` 仍是 O(n²)（M3）；双进程 `two_process` Demo 的发现时序问题未修（M3）。
